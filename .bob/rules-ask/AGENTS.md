# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Where things actually live

- **Diff text** — stored only in `mapSnapshot.Diffs` (map[NodeID]string), never in the HTTP graph response. The graph JSON the frontend receives has no diffs.
- **Open targets** — `mapSnapshot.OpenTargets` maps NodeID → absolute path on disk. These are never serialised to the client (the graph response strips them).
- **Change summaries** — generated by `map_description.go` using a local heuristic, not an LLM. The `changeSummary` struct fields (`Previous`, `Current`, `Changed`, `Impact`) are plain strings computed at snapshot-build time.
- **Activity data** — `map_api.go` computes commit counts in three windows (30/90/all) per file. The `mapFileActivity.RecentCommits` slice is capped at build time; its length is not configurable at runtime.

## Non-obvious data model facts

- `NodeID` is a **forward-slash relative path string** (`filepath.ToSlash` applied at node-creation time in `map_build.go`). Windows absolute paths will never appear as NodeIDs.
- `mapNodeResponse.Openable` is set on the HTTP graph response; the actual path is only in the server-side `openTarget`. The client never knows the absolute path.
- `changeStatus` constants are single-letter strings (`"A"`, `"M"`, `"D"`, `"R"`) matching Git's short status notation — not the go-git enum values.
- `excludedFolders` (excluded.go) is checked case-insensitively inside watchers and scanners. Adding a new excluded folder there also stops the file watcher from tracking it.

## Bob integration context

- `ImpactAnalysis` is the **LLM layer only** — the deterministic evidence lives in `ImpactContext`. The combined `/api/impact` response wraps both in `impactResponse{Context, Analysis}`.
- `bob run --format json` stdout is the `bobResult` envelope; the actual assistant output is in `last_message`. Bob's spinner/progress goes to stderr, which is intentionally not captured.
- Bob exit code 3 = not authenticated. Any other non-zero = generic failure.
